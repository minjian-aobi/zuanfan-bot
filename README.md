# 奥比岛钻饭助手

《奥比岛：梦想国度》自动吃钻饭助手。挂在 MuMu 模拟器上，拜访家园、点三星、抓虫，吃满当天上限就停。

本项目开源免费，基于 [AGPL-3.0](LICENSE) 协议发布。**如果你是花钱买到的，你被骗了。**

## 项目主旨

这是一个**非盈利、免费、全部源码公开**的个人小项目，唯一目的是**解放双手**：把重复点击钻饭的操作交给电脑。

- **只做你手动也能做的事**：脚本只是截图看屏幕、模拟手指点击，相当于替你点按钮。**不读写游戏内存、不修改游戏文件、不拦截或修改网络数据、不破解任何数据**。
- **不做反检测**：本项目不会加入任何防检测、绕过封禁的功能。
- **代码全部公开**：每一行都能在仓库里看到，没有隐藏功能、不收集任何数据、不联网上传任何东西。

如果游戏官方认为本项目不妥，请通过 GitHub 联系，我会配合下架。

## 功能

- **关注列表巡回**：按关注列表挨家拜访，吃到的保留关注，没饭的自动取关；每天第一次运行还会先清掉列表里没饭的人
- **世界频道蹲饭**：盯着世界频道 1 号，看到「钻饭」消息就点进去吃
- **两档模式**：不点关注，只吃无限制钻饭 / 全部关注、关注过的不再进门
- **晶钻计数**：读屏幕上的晶钻数，比开工时多出 100 颗（当天上限）就回家收工，不白跑
- **多账号**：面板里切换账号，每个号的晶钻记录和清理记录分开存
- **卡死自愈**：掉线或卡住 1 分钟会自动重启游戏，回到世界频道接着跑
- **控制面板**：开始、暂停、收工、切档位，都在一个小窗口里点

## 快速开始

只支持 Windows + MuMu 模拟器 12。官服账号或其他 MuMu 模拟器可下载的渠道服。

1. **下载**：点页面上方绿色的 **Code → Download ZIP**，解压到任意文件夹（会用 git 的直接 `git clone`）。
2. **一键安装**：双击 `install.bat`，等它跑完就行，已经装过的会自动跳过。它会装这几样：
   - **Python 3.12**：脚本用 Python 写的，要靠它运行
   - **OpenCV、NumPy、pytesseract**：认屏幕画面用的 Python 库，国内网络会自动换清华镜像
   - **Tesseract**：读晶钻数用的识字程序。装不上也能跑，只是开工时要手动输入晶钻数

   全部从官方渠道下载（python.org、PyPI、winget）。`install.bat` 本身也是公开源码，用记事本打开就能看到它做的每一步。
3. **设置模拟器**：MuMu 分辨率设为 **960 x 540**，DPI 设为 **220**。脚本按这个分辨率认画面，设成别的就认不出来。
4. **下载并登录游戏**：下载提示见图片。第一次请手动登录好游戏账号，之后脚本能自己拉起游戏。
官服游戏下载链接：https://aobi.leiting.com/home?id=M393410
下载时间较长。下载完成后就能在模拟器的桌面看到奥比岛了。

## 使用

打开 MuMu、进入游戏，然后双击 `start.bat`，在面板上：

1. 选账号（可以直接输入新名字建号）（账号名不会被上传，只用于本地标记，方便多账号管理）
2. 确认「晶钻计数」的上限，默认 100 颗
3. 勾选要跑的流程：「先吃关注列表」和 / 或「后吃世界频道」
4. 选世界频道的运行模式
5. 在游戏自己家家园页面（或者任何能清晰看到自己的晶钻数，且能点开世界频道的页面）点「开始运行」

每天首次运行时，脚本会自动识别晶钻数目，强烈建议人工核对识别是否正确，否则会影响当天吃饭次数。
跑起来以后可以随时暂停、继续、收工。**那个黑色命令行窗口不要关**，运行过程也打印在那里。

### 模式怎么选
注意！若勾选了“先吃关注列表”，程序会自动取关很多没饭的账号。如果介意，千万不要勾选。
| 模式 | 做什么 | 适合 |
| --- | --- | --- |
| 无限制 | 只吃无限制钻饭，粉丝钻饭直接跳过 | 不想多关注人 |
| 全部关注查重 | 每家都关注，看到「已关注」就知道吃过了，不再进门（默认） | 长时间挂机，配合关注列表巡回最省时间 |

### 小建议

- 挂机时别用鼠标去点模拟器，暂停后再动手

## 常见问题

**提示找不到 adb / 连不上模拟器**
先确认 MuMu 已经打开。启动窗口里应该能看到一行 `127.0.0.1:16384   device`。还是不行的话，在 MuMu 安装目录里搜索 `adb.exe`，把它和同一个文件夹里的 `AdbWinApi.dll`、`AdbWinUsbApi.dll` 三个文件一起复制到脚本文件夹里。

**一直找不到钻饭、点不中按钮**
九成是分辨率不对，回去检查是不是 960 x 540、DPI 220。

**晶钻数读不出来**
再双击一次 `install.bat`，看第 4 步 Tesseract 装上没有。装了还读不出，就在弹窗里手动输入当前晶钻数，不影响吃饭。

**卡在某个界面不动了**
等 1 分钟，脚本会自己重启游戏。重启 3 次还不行会停下，这时去模拟器里看一眼卡在哪，手动处理后重新开始。
